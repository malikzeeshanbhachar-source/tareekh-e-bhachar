# تاریخِ بھچر (Tareekh-e-Bhachar)

دنیا بھر میں آباد **بھچر (Bhachar)** قبیلے کی مستند تاریخ، روایات، تاریخی مراکز اور شجرۂ نسب کے تحفظ کا جامع ڈیجیٹل منصوبہ اور کتاب۔

## اس ویب سائٹ / کتاب میں کیا شامل ہے؟
* **نسب و شناخت:** بھچر قبیلے کا نسبی پسِ منظر، روایات اور تاریخی جڑیں۔
* **تاریخی حوالہ جات:** گزیٹیئرز اور مؤرخین کی روشنی میں قبیلے کا تذکرہ۔
* **تاریخی ادوار (ٹائم لائن):** قدیم آبادکاری سے لے کر قیامِ پاکستان اور عصرِ حاضر تک کے اہم مراحل۔
* **مراکز و دیہات:** واں بھچراں، ضلع میانوالی، خوشاب، تھل، تلوکر اور دیگر علاقوں کا تعارف۔
* **نمایاں شخصیات:** قبیلے کی علمی، سماجی، عسکری اور عوامی شخصیات کا ذکر۔
* **کتاب اور ابواب کا پیش منظر:** کتاب **"تاریخِ بھچر"** کا تعارف اور ابواب کے اقتباسات۔
* **شجرۂ نسب اور رابطہ فارم:** کتاب کے حصول یا خاندانی شجرۂ نسب کے اندراج کے لیے رابطہ سیکشن۔
